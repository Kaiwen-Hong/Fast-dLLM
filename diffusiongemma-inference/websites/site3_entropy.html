Part 3 / 6 · Entropy-Bound Sampler

熵,是这个模型的组织原则

DiffusionGemma 每一步"锁定"哪些 token,完全由熵 entropy 决定 —— 低熵(有把握)的先定,高熵(还在犹豫)的打回噪声重来。这一篇拆开熵界采样器(EntropyBoundSampler)的三个部件:温度退火、熵界接受、重新加噪。

Mechanism 1 · 熵界接受

为什么是"接受最低熵的一批"?

采样器把所有位置按熵从低到高排序,然后接受最靠前的一段,使得这段的"联合互信息上界"不超过 entropy_bound = 0.1。直觉:这样选出的 token 彼此近似独立,可以安全地一次性并行确定,不会互相打架。

accept 前 k 个(按熵升序),使得   Σ H_i − max(H_1..H_k) ≤ 0.1   ⟺   除最后一个外的熵之和 ≤ 0.1

每根柱 = 一个位置的熵(已按升序排)。青色 = 本步被接受。拖动 bound:调大 → 一次锁定更多(更快、更冒险);调小 → 更保守(更慢、更稳)。

接受 accepted 0 / 0 个位置 并行度 0% 被打回噪声 renoised 0
这就是"并行度 vs 质量"的旋钮 · entropy_bound 越大,每步接受越多、forward 次数越少(越快),但越可能锁错;越小越稳但越慢。官方默认 0.1 是平衡点。把它拖到 0 你会看到几乎只接受那些熵≈0 的位置(通常是 <pad>)。
Mechanism 2 · 温度退火

先高温探索,后低温收敛

logits 在采样前会除以一个温度,温度随去噪步从 0.8 线性退火到 0.4。早期高温 → 分布更平、鼓励探索;后期低温 → 分布更尖、快速收敛到确定答案。注意去噪是反向进行的(step 从 48 递减到 1)。

温度 vs 去噪步

temperature = 0.4 + (0.8 − 0.4) × (step / 48)

step=48(最早)→ T=0.8;step=1(最晚)→ ≈0.41。
配合熵界接受:高温期熵普遍偏高 → 接受得少;随着温度降、模型也更笃定 → 熵下降 → 每步接受越来越多。

Mechanism 3 · 重新加噪

没被接受的,重填随机 token(不是 MASK)

这是 DiffusionGemma 和 LLaDA/Dream 最本质的区别之一:被拒绝的位置不会保留成 [MASK] 等待,而是整个重新采成一批随机词表 token(uniform / random-token diffusion),下一步再被模型"看着噪声重新预测"。

x_next = where(accepted, 已定的 token, 全新随机 token)

好处:每一步模型都在"真实分布下的样本"上工作,而不是特殊的 [MASK] 占位符;坏处:实现上更"重"。Part 6 会正面对比两种范式。

Code × values · 代码 × 数值追踪

把代码和它产生的每个数值对起来

前面讲了机制,这里"上手术台":用两个真实推理的例子,一步步看哪行代码算出哪个数、下一步怎么变 —— 详细到每个位置、每次接受。

A代码架构:两层循环

外层对一块块 256-token 的 canvas 做块自回归;内层对每块做 48→1 的反向去噪。核心就这一段(简化自 generation_diffusion_gemma.py 的 generate() + _denoising_step()):

# 外层:块自回归,一块 256 token 接一块 for _ in range(max_new_canvases): model(prev_tokens) # 前文进 KV cache canvas = sampler.initialize_canvas() # ← 全随机 token 初始化(不是 [MASK]) # 内层:反向去噪,cur_step 从 48 递减到 1 for cur_step in reversed(range(1, 49)): ① logits = model(canvas, self_cond_logits) # 前向:每个位置的 logits ② logits = logits / temperature(cur_step) # 温度退火 0.8→0.4 ③ cand = multinomial(softmax(logits)) # 采样候选 token ④ canvas = sampler.accept_canvas(canvas, cand, logits) # 熵界接受低熵集合 ⑤ canvas = sampler.renoise_canvas(canvas) # 未接受的重填随机 token self_cond_logits = logits # self-conditioning ⑥ if stable_and_confident(): break # 自适应早停 output += argmax(logits) # 这块定稿 = 最后一步的 argmax

④⑤ 是 Part 3 前半讲的熵界接受 / renoise,② 是温度退火,⑥ 是 Part 4 的早停。下面把 ①→⑥ 在真实数值上跑一遍。
