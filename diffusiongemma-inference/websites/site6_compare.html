Part 6 / 6 · vs Mask Diffusion

和 LLaDA / Dream 到底差在哪

你在 Fast-dLLM 里熟悉的 LLaDA、Dream 是 mask diffusion:画布从全 [MASK] 开始,逐步 unmask。DiffusionGemma 是 uniform / random-token diffusion:画布从随机词表 token 开始,逐步 renoise。这一篇把两者并排讲清,并帮你把已有经验迁移过来。

Side by side · 并排看去噪

同一句话,两种"噪声"

点 ▶ 同时播放。左边:灰色 [MASK] 逐个被揭开、揭开后就不再变;右边:红色随机 token 一直在闪动,直到被"锁定"成青色。两者最终都得到同一句话。

Mask diffusion(LLaDA / Dream)

canvas = 全 [MASK] → 逐步 unmask

DiffusionGemma(random-token)

canvas = 随机 token → 逐步 accept + renoise
step 0

关键差别:mask diffusion 用一个特殊吸收态 [MASK] 当噪声,揭开即定;DiffusionGemma 用真实随机 token 当噪声,没锁定的每步都重新随机 —— 所以它每一步都在"真实分布的样本"上工作。

Knowledge transfer · 迁移到你的数据集

把 Fast-dLLM 的经验搬过来

你说"想知道中间步骤好 debug"。下面是从 LLaDA/Dream 心智模型到 DiffusionGemma 的对应关系 —— 你原来在哪 hook,现在就在哪 hook。

抓中间态的 hook 点

LLaDA 里你看 get_transfer_index 的 x / confidence;这里 monkeypatch EntropyBoundSampler.accept_canvas,拿 current_canvas / argmax / token_entropy / accepted_mask。

"解码顺序"信号

LLaDA 用 max-prob / margin / neg-entropy 排序;DiffusionGemma 用纯熵升序 + 互信息界。想改并行度,调 entropy_bound(类比你调 threshold)。

block / 半自回归

Fast-dLLM v2 的 nested block 对应这里的 canvas_length=256 外层块循环;每块内部做完整去噪后进 KV cache,再做下一块。

评测 harness

lm-eval 那套答案提取仍适用,但注意 DiffusionGemma 的输出有 <|channel>thought…<channel|> 结构 —— 取最后一个 <channel|> 之后为最终答案(见 Part 5)。

一句话迁移 · 把"哪些位置还是 MASK"换成"哪些位置还是随机噪声",把"按 confidence unmask"换成"按 entropy accept",你在 Fast-dLLM 里的调试直觉几乎原样成立。
