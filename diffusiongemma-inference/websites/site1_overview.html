Block-Diffusion LLM 推理

DiffusionGemma 不是一个字一个字往右写(autoregressive),而是把一整块 256 个 token 的画布(canvas)从随机噪声并行地逐步去噪(iterative denoising)成答案。这个系列用真实的中间步骤数据,带你逐帧看懂它到底怎么"想"。

One-line essence · 一句话本质
每一步,模型看着当前半是噪声的画布,
把它最有把握(lowest entropy)的一批位置确定下来,
其余位置重新打回随机噪声 —— 循环往复,文字逐渐结晶。

注:与 LLaDA / Dream 等 mask diffusion 不同,DiffusionGemma 的"噪声"是真实的随机词表 token(uniform / random-token diffusion),不是 [MASK]。这一点在 Part 6 详细对比。

The core contrast · 核心对比

自回归 vs 块扩散

同一句"The sky is blue",两种生成范式的差别一目了然。点 ▶ 看它们如何产出。

Autoregressive(如 GPT / 普通 Gemma)

从左到右,一次一个 token,后一个依赖前一个。

forward 次数 ≈ token 数 · 0

Block Diffusion(DiffusionGemma)

整块并行去噪,每步"锁定"多个高置信位置。

forward 次数 = 去噪步数 · 0

真实数据里,"The sky is blue…"这段 53 token 的回答,块扩散只用了 7 步 forward(平均每次前向产出 7.6 个 token);自回归则需要 ~53 次。并行度正是扩散 LLM 的速度来源。

The algorithm · 采样算法

一次生成里发生了什么

外层对 canvas 做"块自回归"(一块 256 token 接一块),内层对每块做 N→1 的反向扩散去噪。下面是内层一步的真实流程。

Denoiser 前向 forward

把当前画布 x_t(含噪声)+ 上一步 logits(self-conditioning)+ 前文 KV cache 一起喂进去,得到每个位置的 logits。

温度缩放 temperature schedule

logits ÷ temperature,温度按步数从 0.8 线性退火到 0.4:早期高温多探索,后期低温快收敛。

采样 + 算熵 entropy

对 logits 做 softmax,采样出候选 token;同时算每个位置的熵 H_i(不确定度)。

熵界接受 entropy-bound accept

把位置按熵从低到高排序,接受累计互信息界 ≤ 0.1 的那批(近似相互独立)的低熵、高把握 token —— 这些被"锁定"。

重新加噪 renoise

没被接受的位置,全部重填随机词表 token(不是 [MASK]),回到下一步继续去噪。

自适应早停 adaptive stop

当画布 argmax 连续几步不再变化(stable)且整体熵足够低(confident),提前结束 —— 简单任务可能只用 2 步。

这套采样器叫 Entropy-Bounded Denoising with Adaptive Stopping。Part 2 会用真实数据逐帧回放;Part 3 深入熵界接受的数学;Part 4 讲自适应算力与并行度。
